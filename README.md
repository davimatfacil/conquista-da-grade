# Conquista da Grade

Jogo para aprender porcentagem a partir da ideia de que 1 quadradinho vale 1%.

- **Missões:** pintar 50%, 25%, 10% e outros valores em uma grade 10x10, sempre com palpite antes.
- **Conquista:** jogo de cartas para completar exatamente 100% e responder "quanto falta?".
- **Mercadinho:** descontos em reais, usando uma tira dividida em partes iguais.

Abre no navegador (Chrome), sem instalar nada. Há um guia para o adulto no topo da página.

Link com nomes personalizados: `?k=NomeDaCriança&a=NomeDoAmigo` no final do endereço.
